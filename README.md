# Odysseia 平台助手（SillyTavern 扩展）

把 Odysseia 平台上的角色卡、世界书、预设一键导入酒馆（SillyTavern），并在作者发布新版本时提醒你更新。

> 目前是测试版，还在完善中。

## 安装

1. 打开酒馆，点顶部的「扩展」（积木图标）→「安装扩展」。
2. 填入本仓库地址：`https://github.com/ODYSSEIA-HQ/SillyTavern-Odysseia`
3. 安装完成后刷新页面，在「扩展」设置里能看到「Odysseia 平台」抽屉。

也可以手动安装：把本仓库下载下来，放到酒馆的 `public/scripts/extensions/third-party/odysseia/`，刷新页面。

## 登录

插件用一枚「插件令牌」登录：

1. 在平台网页打开「设置 → 酒馆插件」，创建一个令牌，起个名字（比如「家里电脑的酒馆」）。
2. 令牌**只显示这一次**，复制下来。
3. 回到酒馆的「Odysseia 平台」抽屉，填写平台地址，粘贴令牌，点「登录」。

令牌丢了或不用了，在平台网页的同一个地方删除，删除后立即失效。插件里的「登出」只是让这个酒馆忘掉令牌。

## 功能

- **一键导入**：把平台上的作品导入酒馆。角色卡、世界书、预设可以一键导入；快速回复、主题、正则等其他类型可以下载后在酒馆里手动导入。
- **粘贴作品链接导入**：粘贴作品页链接（或作品编号），导入最新版本。
- **更新提醒**：酒馆启动时和之后每 6 小时检查一次导入过的内容有没有新版本，有新版时提醒你，可以一键更新。
  - 角色卡更新会替换你对卡本身做过的修改，**聊天记录保留**。
  - 不想要某个版本可以忽略，之后再有更新的版本还会提醒。
- **受限作品**：令牌的权限和你的账号一样，账号看不到的作品插件也导入不了，插件会说明原因。

导入角色卡时，插件会在卡里记下来源作品和版本编号（`data.extensions.odysseia`），用来识别更新；世界书和预设的来源记在插件自己的设置里。如果你已经有同名的世界书，插件会改名导入，不会覆盖你自己的。

## 隐私说明

- 令牌和酒馆其他扩展设置一样，保存在你的酒馆的设置文件里。能访问你酒馆的人也能看到它；觉得不安全时随时在平台删除令牌。
- 插件只会向平台发送：令牌、要导入的作品信息请求、检查更新时已导入内容的作品和版本编号。
- 插件**不会**发送你的聊天记录、角色卡内容、酒馆的其他设置或你本地的其他角色和世界书列表。
- 插件只和你填写的平台地址通信。

## 开发

不需要构建，酒馆直接以 ES 模块加载 `index.js`。和酒馆打交道的部分都在 `src/tavern.js`。

```bash
npm install
npm test
```

本插件没有使用 SillyTavern 的代码。
